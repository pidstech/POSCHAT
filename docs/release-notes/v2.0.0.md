# POSCHAT 2.0.0 — 정식 공개판

공개 배포용 최종 버전이다. 창의 제목 표시줄(최소화·최대화·닫기 버튼)을 되돌리고, 공개 전에 전체 코드를 다시 검토해
데이터 손실·개인정보·승인 우회로 이어질 수 있는 문제를 고쳤다.

## 창

- **최소화·최대화·닫기 버튼 복구**: 1.19.1부터 앱이 처음부터 *전체 화면*으로 열려 창의 제목 표시줄과 버튼이 보이지 않았다. 기본값을 **최대화**로 바꿔 화면을 채우면서 버튼이 보이게 했다.
- 1.19.x는 설정을 저장할 때마다 고르지 않은 창 크기까지 함께 저장했다. 그렇게 남은 *전체 화면* 값은 한 번 지워 새 기본값(최대화)을 따른다. 이제 창 크기는 설정에서 바꿨을 때만 저장한다.
- **F11**로 전체 화면을 끄면 최대화돼 있던 창은 최대화로 돌아온다(전에는 버튼 없는 화면 크기의 창처럼 남았다).
- 설정 → *시작할 때 창 크기*에서 전체 화면을 고르면 제목 표시줄이 숨는다는 것을 설명에 적었다.

## 데이터 보호

- **API 키가 지워지던 문제**: 시작할 때 키체인 접근을 거부했다가(macOS 업데이트 직후 묻는 창) 다음에 허용하면, 비어 보이던 설정이 저장되면서 저장된 API 키 다섯 개가 모두 지워졌다. 이제 비밀 저장소를 읽지 못한 동안에는 키를 지우지 않고, 나중에 읽히면 되살린다.
- **동기화가 대화를 지우던 문제**: 이 기기의 대화·PO노트 파일을 잠깐 읽지 못하면(깨진 파일·백신이 잠금) '지운 것'으로 보내 다른 기기의 멀쩡한 사본까지 지웠다. 이제 파일이 정말 없을 때만 지운 것으로 본다.
- **파일 저장**: 대화·설정 파일을 쓸 때 임시 파일 이름을 매번 다르게 하고 디스크에 내려 둔 뒤 바꾼다(동시에 쓰거나 정전 뒤 파일이 깨지지 않게). 손으로 고쳐 형식이 틀린 `config.json`도 앱이 열린다.
- **PO노트 전사**: 받아 적기와 서버 보정이 동시에 전사를 고칠 때 한쪽 구간이 사라지던 문제를 고쳤다.
- **논문 URL**: 이름이 같고 주소가 다른 PDF(예: `openreview.net/pdf?id=…`)를 열면 먼저 연 논문이 열리던 문제를 고쳤다.

## 개인정보·승인

- **브라우저 에이전트**: 이름표 없는 입력 칸에 친 비밀번호·인증 번호가 칸 이름으로 모델에 가던 문제를 고쳤다. 민감한 칸의 값은 읽지 않는다. 이름이 애매한 링크('더보기')로 승인하지 않은 사이트·내부망에 갈 때도 사이트 승인을 받는다.
- **PLMS 로그인**: 브라우저 에이전트가 쓰는 웹 뷰를 PLMS 로그인 페이지로 옮기지 않는다.
- **직접 고른 로컬 모델**: 로컬 답이 실패해 Cloud로 넘길 때도 *민감 정보·첨부는 로컬만* 설정을 지킨다.
- **인터넷 MCP 도구**: 논문(paper)·Firecrawl 도구에 에이전트가 만든 주소를 넘기면 `web_fetch`처럼 확인을 받고, 내부망 주소는 막는다(리디렉션도 한 단계씩 확인).
- **검색·문서 색인**: 작업 폴더 밖을 가리키는 파일 링크(예: `notes.txt → ~/.aws/credentials`)는 읽거나 색인하지 않는다.
- **자동 실행 설정 파일**: 채팅 에이전트도 `.vscode/tasks.json`·`.husky/`·`.envrc`처럼 폴더를 열거나 커밋할 때 저절로 실행되는 설정 파일을 쓰거나 받을 때 '수정 자동'이어도 매번 묻는다(Code 에이전트의 파일 받기도 같다).
- **채팅 에이전트 명령**: 시간이 지나 멈출 때 셸뿐 아니라 자식 프로세스까지 끝낸다(`npm run dev` 같은 명령에서 에이전트가 멈추거나 프로세스가 남던 문제).

## Code·Lab

- **Git 안전 설정**: 에이전트 탭의 Git 요약·검토·격리 작업 공간도 Git 화면과 같은 안전 설정을 쓴다. 저장소의 `.git/config`(core.fsmonitor·textconv·filter·hook)가 폴더를 여는 것만으로 프로그램을 실행하던 길을 막았다.
- **격리 작업 공간(worktree)**: 하위 폴더를 작업 폴더로 열었을 때 적용(`/apply`)이 폴더 밖 변경을 조용히 빠뜨리고 브랜치를 지우던 문제를 고쳤다. 모두 적용된 것을 확인한 뒤에만 정리한다. 한글(CP949) 파일과 한글 파일 이름도 깨지지 않는다.
- **다시 묻지 않기 규칙**: 에이전트가 `package.json`·`Makefile`처럼 명령의 내용을 정하는 파일을 고친 작업에서는 기억한 명령(`npm test` 등)도 다시 묻는다.
- **품질 검증**: 로컬 모델의 올바른 Code 에이전트 동작(glob·multi_edit·web_fetch 등)을 실패로 보고 Cloud로 넘기던 문제를 고쳤다.
- **다른 인코딩 파일**: 에이전트가 UTF-8·CP949가 아닌 파일(Latin-1·Shift-JIS 등)을 고치면 읽지 못한 글자가 모두 깨져 저장되던 문제를 막았다. 편집기처럼 이런 파일은 고치지 않고 알려 준다.
- **Lab**: 코드 화면에 원격(SSH) 폴더가 열려 있어도 Lab은 이 PC의 작업 폴더에서 실행한다.
- **휴지통**: 같은 파일을 1초 안에 두 번 지우면 앞의 사본이 덮이던 문제를 고쳤다.

## 화면

- 대화가 끝나도 대화별 모델 고르기가 회색으로 남던 문제, Esc 한 번에 겹친 창이 모두 닫히던 문제(승인 창 위에서 설정 창까지 닫혀 입력한 키가 사라짐), 연결·도구의 탭을 빨리 바꾸면 다른 탭 내용이 보이던 문제, 대화 이름을 바꾸는 중에 다른 대화가 끝나면 입력이 사라지던 문제를 고쳤다.
- 코드 화면에서 저장하지 않은 탭을 둔 채 작업 폴더를 바꾸면 Ctrl+S가 다른 폴더의 같은 경로에 쓰던 문제를 고쳤다. 원래 폴더로 돌아가야 저장된다.

## 한계

- 창 제목 표시줄과 웹페이지 위 막대는 Windows·macOS 네이티브 화면이라 CI에서 확인하지 못한다. 실제 기기에서 손으로 확인해야 한다.
- 1.19.x에서 직접 *전체 화면*을 골랐던 사용자도 한 번은 최대화로 열린다. 설정에서 다시 고르면 그대로 유지된다.
- Gmail 보내기 승인 창은 받는 사람·제목만 보여 준다(숨은 참조·본문 미리 보기는 다음 버전). Content-Security-Policy, 문서 압축 폭탄 크기 제한, DNS 재바인딩 대응도 다음 버전으로 미뤘다.
- Windows SmartScreen·브라우저 다운로드 경고는 코드 서명 인증서가 있어야 없어진다(로드맵 Future Work).
