# POSCHAT 2.3.1 — 더 빠르고 덜 끊기는 업데이트

## 고친 점

- **끊겨도 이어서 받기**: 업데이트 파일(Windows 약 90MB, Linux 약 290MB)을 받다가 연결이 끊기면 처음부터 다시 받지 않고 받은 데부터 이어 받는다. GitHub에서 받다가 업데이트 서버로 넘어가도 이어 받는다. 다 받은 뒤에는 지금처럼 크기·SHA-256·서명을 확인한다.
- **느린 곳은 건너뛰기**: GitHub 파일 서버가 너무 느리면(20초 동안 평균 150KB/s 미만) 업데이트 서버로 옮겨 이어 받는다. 업데이트 서버가 안 되면 원래 곳에서 마저 받는다.
- **멈춘 것처럼 보이던 대기 줄이기**: 응답이 끊긴 연결을 2분 동안 기다리던 것을 30초로 줄였다.
- **취소**: 업데이트 창의 '취소'나 창 닫기로 내려받기를 멈출 수 있다. 다시 업데이트하면 받은 부분부터 이어 받는다.
- **Windows 설치 한 번에**: 앱에서 '업데이트'를 누르면 설치 프로그램이 앱이 닫히기를 기다렸다가 바로 설치하고, 끝나면 새 버전을 연다('설치'·'마침'을 다시 누르지 않아도 된다). 바탕화면 바로가기는 이전 설치를 따른다.
- **디스크 정리**: 지난 업데이트에서 받은 설치 파일을 앱이 시작할 때 지운다.

이 개선은 2.3.1로 업데이트한 다음 업데이트부터 적용된다. Windows의 '설치 한 번에'는 설치 프로그램 쪽 변경이라 이번 2.3.1 업데이트부터 적용된다.
