# POSCHAT 2.1.1 — PO노트 서버 보정이 멈추던 문제

## 고친 점

- **녹음 중 서버 보정이 끝까지 멈추던 문제**: PO노트 하이브리드 받아 적기(로컬 AI + POSTECH 보정)는 크레딧 예산 보호(*음성 인식 설정 → 크레딧 예산 보호*)를 위해 가장 최근 크레딧 값을 본다. 녹음 중에 아래쪽 크레딧 **확인**을 눌러 이 값이 예산 아래로 바뀌면 서버 보정을 멈췄는데, 멈춘 동안에는 서버를 부르지 않으니 크레딧 값이 다시 오지 않아 녹음을 끝낼 때까지 보정이 돌아오지 않았다. 이제 멈춘 동안 2분마다 크레딧을 다시 확인하고(크레딧을 쓰지 않는 요청), 예산이 남아 있으면 바로 다시 보정한다.
- **멈춘 동안의 구간도 고침**: 보정을 멈춘 사이에 받아 적은 구간(약 2분 분량까지)은 버리지 않고, 보정이 다시 시작되면 다음 묶음과 함께 고친다.
- **멈춤·다시 시작 표시**: 예전에는 녹음마다 처음 한 번만 알려서 두 번째부터는 보정이 말없이 멈췄다. 이제 멈출 때마다 알리고, 녹음 표시줄에 *서버 보정 멈춤(크레딧 예산 보호)*을 남기며, 다시 시작하면 알린다.
- 녹음을 시작할 때의 크레딧 확인도 **확인** 버튼과 같은 POSTECH 주소에 묻는다(다른 OpenAI 호환 주소를 설정했을 때 두 값이 어긋나지 않게).

## 한계

- 이번 주 남은 크레딧이 정말 예산(기본 30%) 아래라면 보정은 계속 멈춰 있다. 예산 보호를 낮추거나 끄려면 *PO노트 → 음성 인식 설정 → 크레딧 예산 보호*에서 바꾼다.
- 실제 POSTECH 서버로 녹음하며 확인하지는 못했다. 시험은 가짜 엔진과 가짜 크레딧 값으로 했다.
