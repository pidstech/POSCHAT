# POSCHAT 2.3.0 — 모델 목록 자동 동기화

## 새로 생긴 점

- **모델 목록 자동 업데이트**: 제공 모델이 바뀌어도(새 모델·이름 변경·서비스 종료) 앱을 새로 받지 않고 모델 목록이 맞춰진다. 앱이 하루에 한 번 공개 저장소의 모델 목록(`models.json`)을 받는다. POSTECH GenAI처럼 서버가 모델 목록을 알려 주지 않는 경우에도 적용된다.
- 이름이 바뀐 모델로 된 대화와 설정은 새 모델로 옮겨지고, 없어진 모델은 그 방식의 기본 모델로 바뀐다.
- '모델 목록 불러오기'로 한 번 받아 둔 개인 Claude·GPT·호환 서버 목록도 하루에 한 번 같은 키로 다시 받는다.
- **설정 → 업데이트**에서 '모델 목록 자동 업데이트'를 끄거나 '모델 목록 확인'으로 바로 받을 수 있다.

## 안전

- 받은 목록은 모델 ID·이름·별칭만 바꿀 수 있고 API 주소·키·다른 설정은 바꾸지 못한다. 형식이 맞지 않으면 버리고 지금 목록을 쓴다.
- 받기만 하고 아무것도 보내지 않는다(GitHub, 받지 못하면 업데이트 서버). 네트워크가 안 되면 지금 목록을 그대로 쓴다.
