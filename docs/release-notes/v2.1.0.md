# POSCHAT 2.1.0 — PLMS 연결 제거

PLMS(POSTECH 학습관리시스템) 연결 기능과 학교 계정 자동 로그인(SSO)을 앱에서 모두 없앴다. 앱은 더 이상 PLMS에 접속하지 않고,
학교 계정을 저장하거나 대신 로그인하지 않는다.

## 없어진 것

- **사이드바 PLMS 창**: 맨 아래 *PLMS(베타)* 버튼과 수업·공지·자료 화면(PDF 미리보기, PowerPoint 열기, 에이전트에게 수업 정리 맡기기)
- **자동 로그인**: 설정의 *PLMS 계정(자동 로그인)* 칸과 PLMS 창의 *계정을 설정에 저장*, 화면에 붙이지 않은 웹 뷰에서 저장된 계정으로 SSO 로그인하던 기능, 로그인 실패 시 10분 재시도 차단
- **에이전트 도구**: 채팅·Code 에이전트의 `plms_courses`·`plms_course`·`plms_read` 도구와 작업 폴더 없이 도는 PLMS 전용 에이전트 모드, 답변 끝의 *확인 범위* 표시
- **브라우저 내부 기능**: PLMS 전용 쿠키 읽기·지우기(Windows WebView2·macOS WKWebView), 숨은 웹 뷰 이동·스크립트 실행
- **문서**: PLMS 사용법·연계 검토 문서, README 기능 표·사용법 가이드·개인정보 처리방침의 PLMS 항목, 로드맵의 *PLMS 과제 제출* 후보

## 업데이트할 때

- 예전에 저장한 PLMS 아이디·비밀번호는 2.1.0을 처음 열 때 OS 보안 저장소(Windows 자격 증명 관리자·macOS 키체인)에서 한 번 지운다. 설정 파일의 PLMS 연결 값도 함께 지운다.
- 내장 브라우저에 남아 있던 PLMS 쿠키는 일반 웹사이트 쿠키와 같이 브라우저 저장소에 남는다. 앱은 더 이상 읽지 않는다.
- PLMS 수업·자료를 물어 둔 예전 대화 기록은 그대로 남는다.

## 한계

- 1.18.4~2.0.0 릴리스 노트와 로드맵의 지난 버전 기록에는 PLMS 내용이 그때 기록으로 남아 있다.
