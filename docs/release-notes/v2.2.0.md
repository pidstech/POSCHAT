# POSCHAT 2.2.0 — Linux 지원

## 새로 생긴 점

- **Linux용 POSCHAT**: `POSCHAT-linux-x86_64.AppImage` 파일 하나로 실행한다. x86_64 PC, glibc 2.35 이상 배포판(Ubuntu 22.04·Debian 12·Fedora 36 이후 등)용이다.
  1. 받은 파일에 실행 권한을 준다: `chmod +x POSCHAT-linux-x86_64.AppImage`
  2. 더블클릭하거나 `./POSCHAT-linux-x86_64.AppImage`로 실행한다. 처음 실행하면 앱 메뉴에 POSCHAT이 등록된다.
  3. FUSE 오류가 나면 `sudo apt install fuse3`를 설치하거나 `--appimage-extract-and-run`을 붙여 실행한다.
- 창은 앱에 함께 들어 있는 Qt WebEngine으로 띄우므로 배포판의 웹 엔진을 따로 설치할 필요가 없다. PO노트 녹음에 쓰는 PortAudio도 함께 들어 있다.
- **자동 업데이트**: Linux판은 새 AppImage를 받아 서명·SHA-256을 확인한 뒤 실행 중인 파일과 바꾼다. 앱을 다시 열면 새 버전이다(AppImage가 있는 폴더에 쓸 수 있어야 한다).
- 대화 기록과 설정은 `~/.config/PostechChat`에 저장된다.

## 한계

- Linux에는 아직 앱 안 **브라우저** 화면이 없다. 채팅·에이전트·PO노트·Code·Lab·MCP는 같다.
- 앱 창은 앱 자신의 화면만 열기 때문에 배포본에서는 Chromium 샌드박스를 끈다(Ubuntu 24.04 AppArmor 제한). `QTWEBENGINE_DISABLE_SANDBOX=0`으로 켤 수 있다.
- ARM(aarch64) Linux용 파일은 아직 없다.
- CI(Ubuntu 22.04, 가상 화면)에서 빌드·자가 진단·창 열기를 확인했고, 실제 데스크톱 배포판에서 손으로 확인하지는 못했다.
