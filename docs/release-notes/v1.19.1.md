# POSCHAT 1.19.1 — 1.19 피드백 후속 수정

1.19.0을 써 본 뒤 받은 피드백 6가지를 반영했다.

## 바뀐 점

- **스킬 설명 한국어**: 플러그인 화면처럼 *스킬* 목록과 입력창의 `/` 메뉴에서도 설치한 플러그인 스킬·명령의 설명을 한국어로 보인다. 영문 원문은 *영문 원문*을 눌러 볼 수 있다. 에이전트(모델)에게는 원문 설명이 그대로 간다. 앱 내장 스킬은 원래 한국어다.
- **처음부터 전체 화면**: *시작할 때 창 크기*의 기본값을 *전체 화면*으로 바꿨다. 1.19.0이 설정을 저장할 때 함께 적어 둔 '기본 창' 값은 한 번 지워 새 기본값을 따른다(최대화·전체 화면을 고른 값은 그대로). 기본 창이 좋으면 설정에서 다시 고르면 되고, 지금 창은 **F11**로 전체 화면을 끈다.
- **주소 칸을 브라우저로**: 주소 입력, 뒤로·앞으로·새로 고침(불러오는 중에는 멈추기)을 채팅 위 주소 줄에서 빼서 웹페이지 위 막대로 옮겼다. 막대에는 *기본 브라우저로 열기*와 *닫기*도 함께 있다. 채팅 위에는 *이 페이지에 대해 묻기*·*선택한 부분 묻기*·*연구 라이브러리에 저장*과 에이전트 진행 표시만 남는다. 브라우저를 열면 막대의 주소 칸에 바로 입력할 수 있다.
- **막대 잘림 수정**: 웹페이지 위 막대의 윗부분이 살짝 가려지던 문제를 고쳤다. 막대 높이를 넉넉히(Windows 42, macOS 40 논리 픽셀) 잡고, 버튼은 크기를 글자에 맞추지 않고 막대 높이를 채운 채 글자를 가운데 놓는다. 주소 칸도 세로 가운데에 둔다.
- **크레딧 막대 그래프**: 설정과 `/usage`의 *POSTECH GenAI 크레딧*에 이번 주기 한도 대비 사용량 막대를 더했다. 70%부터 노랑, 90%부터 빨강으로 바뀐다. 한도를 모르면 막대를 숨기고 글자만 보인다.
- **링크 색 밝게**: 링크 색을 더 밝게 했다(어두운 화면 `#a8d1ff`, 다녀온 링크 `#d9c2ff`). 플러그인 *홈페이지*처럼 버튼 모양 링크가 브라우저 기본 파랑(어두운 화면에서 어둡고 탁함)으로 보이던 것을 링크 색·밑줄 없음으로 바꿨다.

## 한계

- 웹페이지 위 막대는 Windows(WebView2)·macOS(WKWebView) 네이티브 컨트롤이라 CI에서는 화면 시험을 하지 못한다. 실제 기기에서 막대 높이·주소 칸·버튼 동작을 손으로 확인해야 한다. 막대를 만들지 못하면 예전처럼 채팅 위 주소 줄이 보인다.
- 막대 색은 Windows에서 OS의 밝음·어두움 설정을 따른다(앱 안 테마 설정과 따로).
- 전체 화면에서 웹페이지(오른쪽)에 입력 초점이 있으면 F11이 앱에 닿지 않는다. 왼쪽 앱 화면을 한 번 누른 뒤 F11을 누르세요.
